# 🏋️ BMI & Calorie Calculator


Application Screenshot https://imgur.com/3DnMIvX
*A comprehensive health calculator for body metrics and nutrition planning*

## ✨ Features

- **4-Step Assessment Process**:
  1. Gender selection
  2. Age input
  3. Height/weight measurement
  4. Activity level evaluation

- **Detailed Health Metrics**:
  - BMI calculation with classification
  - Basal Metabolic Rate (BMR)
  - Weight maintenance calories
  - Calorie targets for weight loss/gain

- **User-Friendly Interface**:
  - Responsive multi-step form
  - Real-time validation
  - Clean, accessible design
  - Mobile-friendly layout

## 🛠️ Technology Stack

| Category       | Technologies Used               |
|----------------|---------------------------------|
| Frontend       | HTML5, CSS3, JavaScript, EJS    |
| Backend        | Node.js, Express.js             |
| Styling        | Custom CSS with responsive design |
| Deployment     | Local server (Node.js)          |
